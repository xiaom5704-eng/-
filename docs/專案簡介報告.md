# 智慧醫療助理（MedSafe AI）專案簡介

更新日期：2026 年 9 月 27 日

## 一、這個專案是什麼？

這是一套結合 AI 對話與藥品資料查詢的網頁系統，協助使用者查找藥品成分、交互作用與藥品說明書，並依諮詢對象的年齡提供一般健康與照護資訊。服務對象涵蓋嬰幼兒、兒童、青少年、成人與高齡者。

它的定位是**教學與專題開發原型**，讓藥品資訊更容易查詢、閱讀與保存，供使用者與醫師或藥師核對參考。

## 二、想解決什麼問題？

藥品的商品名、成分名稱與說明書往往不容易理解。使用者同時查詢多款藥時，也可能難以發現它們含有相同成分。本專案將不同資料來源整合到同一個畫面，先呈現重要提醒，再讓使用者展開原始資料。

## 三、主要功能

| 功能 | 使用者可以做什麼 |
| --- | --- |
| 藥品搜尋 | 輸入中文藥名、英文名稱或許可證字號，確認要查詢的品項。 |
| 藥錠照片比對 | 預設以本機 DINOv2 模型找相似參考圖，可裁切、上傳正反面及補充刻字；核對候選後才確認品項。 |
| 文字與 PDF 辨識 | 切換本機 OCR 讀取藥袋、外盒或藥錠刻字，校正後查本機資料；Gemini 為選用輔助。 |
| 本機外觀查詢 | 使用 TFDA 外觀 CSV，依刻字、顏色與形狀找候選，並用許可證字號接上成分資料；手動查詢不需 AI。 |
| 用藥提醒 | 比對成分，提示重複成分、已查得的交互作用，以及資料不足的部分。 |
| 一鍵比賽案例 | 載入 Noscapine、Somin、Cypromin、K.B.T、Fencaine 的指定示範品項，切換年齡並查看有來源的提醒；不需 Gemini 或 Ollama。 |
| 藥品說明書 | 依許可證及完整品名查臺灣官方仿單入口、閱讀已保存文件，以及成分相符的美國仿單原文；官方外盒可逐頁保存、放大並核對後加入本機比對。 |
| 依年齡對話與症狀諮詢 | 填寫年齡（歲／月／天）或在問題中說明，由 Gemini 或本機 Ollama 參考實際年齡提供一般照護資訊、追問與就醫提醒。 |
| 紀錄與摘要 | 儲存對話及藥品查詢報告，產生多語查詢摘要，方便再次查看。 |

## 四、如何使用？

**輸入藥名或上傳檔案 → 確認藥品 → 查詢資料 → 閱讀提醒與說明書 → 儲存報告。**

結果頁分為「用藥提醒」與「藥品說明書」。重複提醒會合併顯示；英文全文、成分編號與完整配對明細可另外展開，減少一次需要閱讀的資訊量。

健康諮詢時可先填寫本人或家人的年齡，再描述症狀。年齡隨問題保存，方便同一對象的後續追問；不同的人應建立新對話。年齡未提供時不預設為嬰兒，AI 會視問題確認所需資料。

## 五、資料與技術

藥品查詢主要使用四個來源：**TFDA** 提供臺灣藥品名稱與成分，**RxNorm** 協助標準名稱對照，**DDInter** 提供交互作用配對與風險等級，**openFDA** 提供相關美國仿單。

系統以 React、TypeScript 與 Tailwind CSS 製作網頁，Express 處理後端請求，SQLite 儲存藥品資料與對話紀錄。聊天與症狀諮詢只使用畫面選定的 Gemini 或 Ollama，失敗後由使用者切換再重試。日常從 VS Code 終端機啟動本機網頁，不需要桌面安裝程式。

**藥品交互作用報告是依資料庫查詢結果整理，並非讓 AI 自行推測。** 中英文藥名、外觀查詢及預設分析使用本機資料庫；藥錠照片由應用程式後端的本機視覺模型比對，文字／PDF 可在瀏覽器用 OCR 讀取，兩者均不需要 Gemini 金鑰或 Ollama。只有選用 Gemini 輔助辨識才上傳雲端，需要時才補查線上標準名稱與仿單。本機 AI 對話仍需要 Ollama 背景服務。

## 六、目前成果與限制

目前已有藥品與外觀查詢、本機照片檢索、照片裁切、本機 OCR 與文字校正、圖片放大對照、交互作用與仿單呈現、依年齡提供資訊的 AI 對話，以及報告儲存流程。本機有 66,495 筆藥品、164,426 組 DDInter 配對、6,318 筆外觀紀錄及 29,875 筆官方仿單／外盒入口索引；這些是本次資料版本的筆數，不代表完整或最新涵蓋。目前服務可查的藥錠圖片索引為 5,787 個品項、6,142 張圖。參考圖透過固定版本的 TFDA 圖片鏡像取得，逐張核對字號與來源；資料更新或來源失效時不繼續提供過期的索引結果。

本機 CV 是通用圖片特徵檢索，尚未用獨立的實拍藥錠資料驗證準確率；外觀相似、背景與刻字不清都可能產生錯誤候選。藥盒另有獨立圖庫，可自行收錄有權使用的照片，或保存官方外盒 PDF／圖片、逐頁核對後加入比對；公開下載初始沒有自存藥盒照片。官方入口數不等於已保存、已核對的圖片數，平面包裝稿亦可能與實拍差異很大。藥袋及未收錄的外盒可用 OCR；OCR 可能混淆 0／O 或 10／16，需人工校正。這些軟體功能不代表臨床有效性驗證。

資料來源仍可能缺漏或無法連線，**查無紀錄不等於沒有交互作用**。一鍵案例另加入按品項與年齡核對的來源規則，可比較 1 個月、4 歲、30 歲及 70 歲；來源版本、資料缺口與藥理推論會明列。這些規則只覆蓋案例的有限品項，不代表所有藥品都已完成年齡審核。DDInter 仍是成分層級篩查，未依劑量、途徑或病況個別判定。美國仿單不能直接視為臺灣產品的用法，本系統也不提供個人化處方或劑量計算。AI 回覆仍可能有誤，重要用藥問題應由醫師或藥師確認。

目前尚未實作登入與使用者資料隔離，同一後端共用對話紀錄。若要提供多人正式使用，仍需完善權限、資料保護與維運機制。
