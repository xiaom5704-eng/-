# 本機臺灣仿單與外盒索引

在「藥物辨識」搜尋並確認藥品後，選「用本機資料分析 → 藥品說明書」，可看到「臺灣官方仿單與外盒」。索引查找在 SQLite 完成，不需要 Gemini、Ollama 或線上查藥 API。

點「查看官方仿單」或外盒的原始來源連結才會開啟食藥署網站，需要網路。部分來源是 PDF，部分 `exportpdf` 入口會轉到品項網頁，再從該頁查看電子／紙本仿單。外盒另可明確保存到本機，流程如下；原先六份人工核對仿單的離線閱讀功能仍獨立保留。

## 保存外盒並加入照片比對

1. 搜尋並確認品項，開啟分析結果的「藥品說明書 → 臺灣官方仿單與外盒 → 查看與保存外盒」。
2. 選擇一份來源，按「保存外盒並預覽」。首次需要網路及已安裝的本機 DINOv2 模型，之後查看不需要網路或 API Key。
3. 點圖放大，逐頁核對中英文品名、劑量、許可證及實際包裝；官方文件也可能有舊版或內容不一致。保存不代表已核對，不新增任何劑量建議。
4. 無疑義的頁面按「已核對第 N 頁，加入比對」，才會被「藥盒照片比對」使用。有疑義的頁面保留預覽即可；已加入的頁面可隨時停用，停用後仍可離線查看。

支援 JPEG、PNG、WebP 及最多 8 頁的 PDF，單一來源最多 8 MiB，下載 30 秒、整體處理 120 秒上限。PDF 全部頁面轉換成功並建立特徵後，才一次保存索引；超限或任一頁失敗，不部分加入。照片轉為最長邊 1600 的 WebP，保留頁碼、來源網址、原檔雜湊、檔案取得日期與索引取得日期。原始 PDF 不作為已保存的仿單全文，不能用外盒圖片推定用法或年齡適用性。

資料位於 `VISION_DATA_DIR/official-packages/`（預設 `data/vision/official-packages/`），與自行收錄藥盒、藥錠圖庫及藥品主檔分開。相同完整來源重試直接沿用，不重複下載或刷新取得日期，也不啟用待核對頁面。檔案損毀或模型版本變更時可重新保存，但需重新逐頁確認。品項或索引連結變動時，舊圖立即退出比對與預覽；必須重新分析後才可取得新來源。

只下載目前本機索引列出的 TFDA 外盒連結，核對完整許可證、品名、成分、劑型與製造商；不接受任意網址或轉址。兩種藥盒來源會一起依既有 0.75 門檻找候選，官方頁面只綁定該許可證，自行收錄的完整品名仍保留同名許可證。平面包裝稿、標籤與實拍可能差異很大，本功能不保證辨識率。下載的個別文件不隨 Git 或現有公開資料包發布，圖片利用條件依個別來源。

## 安裝與更新

首次 `npm run data:install` 會自動補入隨原始碼提供、固定 SHA-256 的官方快照。原公開 160 MB ZIP 沒有被重發或覆寫。

已有資料庫或手動解壓資料包的使用者，在專案根目錄執行：

```powershell
npm run data:import-labels
```

這是離線補入：若已經有索引，保留已有內容及日期。先在資料庫旁的 `backups/` 保存 SQLite 備份；不更動藥品、外觀、DDInter、成分對照或已核對 PDF。資料位置沿用 `.env` 的 `DRUG_DB_PATH`；沒有主檔時不建立空資料庫。

需要更新官方索引時，明確執行：

```powershell
npm run data:import-labels -- --download
```

僅向 [TFDA 固定 JSON ZIP 網址](https://data.fda.gov.tw/data/opendata/export/39/json) 下載索引，限 20 MiB、60 秒，原始 ZIP 留在資料庫旁的 `raw/`。解析完整成功後才在單一交易替換索引；來源失敗、欄位不符、重複許可證、非預期連結或 SQL 錯誤均保留舊索引。相同內容不刷新原日期。這個指令不下載所有 PDF／外盒圖片。

## 資料範圍與核對方式

2026-09-27T14:49:31.588Z 取得的 [官方資料集 9117](https://data.gov.tw/dataset/9117) 有 29,875 個品項，其中 27,550 個有可保留的仿單入口、20,961 個有外盒連結；兩者會重疊。原始資料另有 12 個沒有檔案識別碼的 `/insert/pdfcase` 不完整連結，程式略過並明示缺口，保留同筆其他有效連結。來源與完整性記錄見 [快照說明](../resources/tfda/README.md)。

對目前 66,495 筆 TFDA 主檔，29,008 筆同時通過許可證、中文與英文全名核對；其中 26,884 筆有仿單入口，20,321 筆有外盒連結，20,964 筆主檔未標示註銷。另有 4 筆許可證相同但品名不同，不自動綁定；863 筆索引許可證不在目前主檔。數字是這次快照的實測，不代表所有品項都有可用或最新文件。

名稱只合併全半形、英文大小寫及空白；不省略規格、括號或品牌。讀取時再次核對目前主檔，外觀獨立紀錄、RxNorm 品項及損毀索引不套用。文件連結只接受對應 TFDA 路徑，`exportpdf` 必須含同一許可證。

**索引匹配只確認品項入口，沒有核對每份文件內容、修訂版本、劑量或年齡適用性。** 開啟文件後仍應核對許可證、規格及版本；本功能不新增任何臨床結論或年齡規則。文件可能失效或改版，未逐一測試所有連結。既有來源不足／未完成交互作用對照等提示保留。

儲存報告時包含索引取得日期、來源、SHA-256 及各文件連結。舊報告不會被新索引改寫；重新分析才使用更新的索引。保存連結不代表保存原文件，離線全文仍以「已保存」的文件功能為準。

2026-09-28 核對完整頁面的品名、許可證與規格。程式目錄 `server/vision/package-starter.ts` 固定品項身分雜湊、原始文件 SHA-256、頁數及已核對頁碼；只有全數符合的新示範頁面才可直接參與候選比對。核對是外觀來源歸屬，不是現售包裝、療效或年齡適用性認證。

檔案直接由 TFDA 下載至本機既有官方外盒圖庫。相同版本重跑不下載、不刷新取得日期，也不啟用使用者原先停用或待核對的頁面；修復圖片同樣保留這些設定。其他官方來源仍沿用逐頁人工核對流程。來源失效、文件改版或主檔變更會顯示原因；個別失敗不取消已完成品項。取消後可重試接續，重新檢查圖片庫即可看到已完成部分。
