# Windows 桌面版

桌面版沿用現有 React／Express／SQLite 架構。程式先啟動只監聽 `127.0.0.1` 的服務，確認資料就緒，再開啟同一來源的介面；作業系統自動分配連線埠，不佔用既有的 3100。

2026-09-24 已重新產生含目前程式及來源資料的安裝包；2026-09-27 原生啟動檢查仍以 `spawn UNKNOWN` 失敗，尚未通過驗證。封裝內容的完整檢查也尚未完成，因此此包暫不作可用桌面版交付。先前 9 月 20 日曾遇到 Windows 應用程式控制封鎖，但不能只憑這次錯誤碼認定原因相同；未更改安全設定。現階段使用網頁版，詳細建置及失敗紀錄在 `test-results/desktop-20260924/` 與 `test-results/desktop-check.json`。

## 建置與執行

先依 README 匯入藥品、DDInter、外觀資料並建立圖片索引，再執行：

```powershell
npm run electron:build -- --dir
npm run electron:check
```

測試包位於 `release/windows/win-unpacked/智慧醫療助理.exe`。若要產生 NSIS 安裝檔，執行 `npm run electron:build`；不會自動上傳或發布。這是未簽署的本機開發版本，不能宣稱已通過 Windows 軟體信譽驗證。目前停用執行檔資源編輯以避免簽章工具的 macOS 符號連結需要額外 Windows 權限，因此 Explorer 的 EXE 圖示／版本仍可能顯示 Electron；應用視窗與網頁使用本機聽診器圖示。

`electron:check` 使用獨立的 `test-results/desktop-profile-*` 目錄，不讀入真實對話，檢查啟動、完整資料、案例、圖片推論、重開後的測試報告與子服務結束。結果寫入 `test-results/desktop-check.json`。圖片測試用現有參考圖驗證原生模組與模型可執行，不是獨立實拍辨識率，也不代表相機、麥克風或桌面視窗外觀已驗證。

開發時用 `npm run electron:dev`，會啟動獨立開發服務並將實際連線埠傳給 Electron，不再硬編碼 3000。開發服務沿用專案 `.env` 與資料路徑；桌面正式版使用下述獨立資料目錄。

## 保存與內建資料

- 首次啟動把 `resources/medsafe-data` 複製至 Electron 的 `userData/store`，逐檔核對 SHA-256 後才完成安裝。中斷或不完整的複製不會當成可用資料。
- 預設 Windows 使用者資料位置為 `%APPDATA%/MedSafe`，聊天在 `medsafe.db`，藥品在 `store/drugs.db`，圖庫在 `store/vision`。以實際 Electron `userData` 為準；完整備份這個資料夾即可保留對話與後續收錄。
- 重開或重新安裝保留既有資料，不用內建快照覆蓋使用者更新。現有資料不完整時明確報錯並保留原檔；不要直接刪除此目錄來修復。
- 包含 TFDA 藥品、DDInter 公開配對、外觀資料、已查核成分與仿單、公開藥錠参考圖、DINOv2 模型、瀏覽器 OCR 模型與來源授權文件。保留原取得日期，不把打包日期當成來源更新日期。
- 不包含開發者 `.env`、Gemini 金鑰、聊天資料庫、暫存 API 查詢或使用者上傳的藥盒照片。新桌面資料的藥盒圖庫從空白開始，可透過既有「收錄已核對的藥盒」建立；目前網頁版的圖庫保持原狀。
- 來源快照的後續更新目前仍需維護者使用既有匯入命令；安裝新版程式不會自動合併新快照。更新前應備份，指定桌面資料的 `DRUG_DB_PATH` 與 `VISION_DATA_DIR`，並關閉桌面程式。

DDInter 遵守 CC BY-NC-SA 4.0，資料與模型的其他授權見 [drug-data.md](drug-data.md) 和 [vision.md](vision.md)。這份安裝包適合目前教學原型，不代表資料可直接改作商業用途。

## 原生套件與安全設定

桌面執行依賴安裝在獨立 `release/app/node_modules`，鎖檔為 `electron/runtime-package-lock.json`。SQLite 桌面版固定 `12.11.1`，其官方發行有 Electron 41／ABI 145 的 Windows x64 預編譯檔；網頁版保留原本 SQLite 套件。Sharp 與 ONNX 使用套件內的 Node-API 執行檔。

electron-builder 的自動依賴重建會向上掃描專案根目錄，因此關閉該步驟；建置腳本只對桌面暫存目錄執行官方 `prebuild-install`。不要對專案根目錄執行 Electron 原生模組重建，以免破壞一般 Node 服務。[Electron 原生模組說明](https://www.electronjs.org/docs/latest/tutorial/using-native-node-modules)、[SQLite 官方版本](https://github.com/WiseLibs/better-sqlite3/releases/tag/v12.11.1)。

視窗停用 Node integration，啟用 context isolation 與 sandbox。外部 HTTPS 來源交由預設瀏覽器開啟。相機／麥克風由使用者按需允許。結束桌面版會關閉所屬本機服務；父程序意外結束時，IPC 斷線也會關閉子服務。

本機資料搜尋、案例及 CV／OCR 不需要 Gemini 或 Ollama；自由問答仍需要可用的模型服務，線上更新及外部來源連結仍需要網路。
