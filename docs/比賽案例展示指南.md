規則更新日期：2026-09-24；各來源的文件版本另列。這是教學展示，不是已完成臨床驗證的處方審核系統。

## 90 秒展示順序

1. **載入案例**：「藥物辨識 → 一鍵載入 1 個月案例」，說明五個品項、八個成分來自本機資料；文章未指定的品項是假設選用，未確認為原處方。
2. **看見依據**：展開一則提醒的來源，開啟本機 PDF，讓評審看到產品、版本與原文。
3. **改變年齡**：按「調整年齡／查詢清單」，比較 4、30、70 歲。說明年齡提醒會變，但 DDInter 成分配對等級不因年齡自動改寫。
4. **呈現資料缺口**：指出已查得的中度配對，以及仍未完成對照的成分；展示的是有依據的核對工具，不能據此宣稱整張藥單安全或危險。
5. **回到 1 個月**：按「1 個月」重新分析，需要留存時再按「儲存報告至對話」。

可用開場：「同一張藥單，年齡不同，需要核對的注意事項也不同。我們讓使用者看見來源、比對結果與資料不足的地方。」

## 操作方式

1. 開啟「藥物辨識」，按「一鍵載入 1 個月案例」。不需要 Gemini 金鑰或啟動 Ollama；仍需啟動本專案服務及備妥本機藥品資料。
2. 系統載入 5 個明列許可證的示範品項，讀取 8 個成分，顯示年齡提醒及資料缺口。
3. 展開提醒的「查看品項與來源依據」，說明該結論來自仿單、用藥資料或藥理推論。
4. 按「調整年齡／查詢清單」，用 4 歲、30 歲、70 歲按鈕比較。一般使用者也能自行填寫歲、月、天；修改後重新分析。
5. 展示下方 DDInter 查詢結果：目前 28 組成分配對中，Somin／Cypromin 的成分有 1 組中度紀錄、2 組已對照但未查得配對，25 組尚未完成對照。展開「查看這項提醒的依據」可見官方來源及 2026-09-23 的快照時間。這不是 28 組危險交互作用，也不能當作個人或該年齡的風險機率。
6. 可按「儲存報告至對話」，保留案例假設、年齡、提醒、來源與原始查詢結果。

同一對話內切到聊天／症狀頁再返回，會保留藥單、年齡、照片與已完成結果；尚未完成的照片辨識會取消，返回後可重試。切換到另一對話或重新整理，未儲存的查詢內容會清空，需要留存請先儲存報告。

本機另已保存此案例的官方 RxNorm 精確對照與版本，重啟仍可使用。Somin 的 dexchlorpheniramine、Cypromin 的 cyproheptadine 及 K.B.T 的 kaolin 現可對應 DDInter；Kaolin 的括號別名沿用同一許可證的 2023-02-24 仿單依據。Somin 的網站補充資料不改動原有鹽類關係；其餘未對照成分保持未知。Albumin tannate 保留仿單核對依據，但沒有 DDInter 名稱。可在「藥品說明書 → 成分、核對狀態與來源」查看日期與來源；維護方式見[本機成分對照](./本機成分對照.md)。

### 照片與文字的展示方式

- 藥錠與藥盒照片模式預設勾選「同時用本機 OCR」，按一次「比對照片並讀取文字」即可取得分開呈現的圖片候選及文字，不需金鑰。核對原圖位置後勾選同一面刻字／同一品名各行，直接查本機資料，無須再跑一次圖片模型。圖片服務失敗仍保留完成的 OCR；也可取消勾選，只執行原本圖片比對。
- 仁慈醫院 K.B.T 完整照片已實際讀出 SK、KBT；人工排除背景與尺規，選取兩行後找到克瀉寧 007592 一筆，確認清單仍為零，沒有自動認藥。此照片的純 CV 仍未找到正確前八名，文字查詢成功不能算成純影像辨識成功。
- 藥錠刻字亦可用本機 OCR：先裁切同一顆的一面，選「單顆藥錠刻字」，讀取後勾選同一面的多行文字再查詢。K.B.T 開發裁切圖已在正式建置網頁读到 SK／KBT 並查到克瀉寧；未裁切多藥照片的自動定位尚未接入，Fencaine 的 10 仍可能誤讀為 16。請將此展示說明為「核對刻字後搜尋」，不是自動判定藥品身分。
- 小於 1280 的藥錠照片會另補讀小字，可在「原尺寸結果／小字補讀結果」之間切換，按每行「查看位置」排除尺規。Fencaine 完整開發照片已實測補讀出 FC、10，選取藥錠上的兩行後，按「用完整刻字查本機資料」找到芬康胃錠 031990；另一個 10 的框位於尺規，不要勾選。這仍需要人工核對，也不表示所有照片能辨識；原尺寸與放大各有漏字／誤讀，校正與位置分開保留。
- 使用者提供的普拿疼藥盒可選「本機 OCR」，執行後勾選「伏冒、普拿疼、加強锭」三行，再按「用選取文字查同一藥品」。簡繁混用已可搜尋到兩筆原文為「普拿疼伏冒加強錠」的許可證；仍須核對手上包裝，不自動替使用者選定其中一筆。
- Drive 的 Somin `01027569.jpg` 實測未在純 CV 前八個候選找到舒敏錠。2026-09-22 修正刻字被圖片門檻排除的漏查後，填入 C 會提示有 19 款同刻字藥錠；按「以此刻字展開完整本機搜尋」可看到舒敏錠。它仍不在前八個圖片／刻字混合候選中，不能以此照片宣稱自動辨識成功。
- 另以 Drive 的 K.B.T、Fencaine 照片檢查，也未在前八個候選找到預期品項。自動裁切實驗未通過，因此未套用正式模型。資料夾標示僅是這次測試的預期品項，不是獨立臨床標註。
- 刻字流程修正後，上述兩張開發照片另填完整刻字 SK KBT、FC 10，各有一款符合的藥錠，分別為克瀉寧錠、芬康胃錠，列為第一個待核對候選。頁面明示「刻字相符・照片未確認」；這是人工文字線索補回資料，沒有提高或宣稱純照片辨識準確率，也不需 Gemini／Ollama。
- 可展示「不用 AI：輸入刻字與外觀查本機資料」：人工對照照片填入圓形、粉、完整刻字 C，目前找到永信舒敏錠一筆，能放大本機食藥署參考圖片。這示範的是人工提供特徵後的資料庫搜尋，仍需核對藥袋或包裝。
- 另可選「使用 Ollama 外觀輔助」：先讀取形狀、顏色與刻字，核對可編輯欄位後按「以核對後特徵查本機資料」。這台電腦現有 qwen3.5:4b 的正式 API 在三張開發照片讀出 C、SK KBT、FC 10，再查到各自預期候選；網頁已實際操作 Somin。這是選用模型協助輸入特徵，不是純 CV 圖片搜尋通過，也不代表獨立準確率。沒有 Ollama 時仍可載入案例及使用原本 CV／OCR／人工特徵查詢。
- 四款案例錠劑已另外保存官方較高解析度來源圖。點圖後可選 2／4 倍，或點兩下藥錠放大該位置；Fencaine 圖片保留 5496×3670，已實際在網頁核對 FC／10 刻字。這改善人工對照，不代表自動 CV 已能辨識案例照片。

目前展示服務已保存「比賽展示：五藥與年齡核對（教學案例）」對話，重新整理後可由側欄開啟；此為教學資料，不是實際病人處方。舊報告保留產生當時的結果，不會隨成分對照更新而改寫；查看最新結果請重新按一鍵載入案例。新安裝環境不附帶開發者對話，仍可用一鍵案例自行產生報告。

各年齡都保留 Somin 與 Cypromin 的藥理重疊提醒：這是兩份來源支持的藥理推論，與下方 DDInter 中度配對分開呈現。DDInter 等級不隨示範年齡改寫，也不能據此計算個人風險。K.B.T 的仿單併用提醒仍不冒充 DDInter 紀錄。

2026-09-23 已為這組 DDInter 配對加入有來源的中文簡述。展開「查看這項提醒的依據 → 閱讀已保存的來源原文」，可離線查看交互作用／處置原文、取得日期與文獻清單；儲存到對話後仍保留。這是依來源整理的藥物類別警語，未證明原案例的症狀因果，也不是依嬰兒個別病況計算的風險。其他配對尚未保存說明時會明確提示，不能宣稱所有已收錄配對都有中文解釋。

2026-09-24 另補入 35 個成分的官方快照，總配對增至 162,950 組；這是本機資料涵蓋的改善，不改寫本案例的九則年齡提醒或 1／2／25 組查核結果。詳細版本見[本機成分對照](本機成分對照.md)。

同日補上官方機轉分類的中文詞義及來源；本案例的配對來源可看到「作用可能增強（synergy）」，原有詳細簡述保持優先顯示。分類本身不判定效益、副作用或嬰兒個人風險。一般查詢若分類不明會保留未知；報告儲存與重開均保留分類、來源及取得日期。

同日補齊五款案例品項的本機 PDF：甜嗽錠、舒敏錠（平台檔名日期 2022-04-26）、希普利敏液（2012 版）、克瀉寧錠、芬康胃錠（2015 歷史版）。可在「藥品說明書」或對應來源開啟，翻頁及放大不需連外；儲存報告的本機 PDF 連結也可重開。五款有文件不代表五款都有最新版或有充分嬰兒資料；2012 希普利敏副本不會附到 2024 來源旁。[來源與維護方式](本機仿單副本.md)。

## 工程驗證與範圍

- 規則保存於 `shared/medication-safety.ts`，按許可證及完整成分集合核對，不依品牌字串相似就套用。資料缺少或成分改變，示範 API 回報錯誤，不偷偷替代產品。
- `POST /api/medications/demo` 只讀本機資料；一般 `/report` 可帶入 `patient`。未提供年齡就不執行年齡條件。
- 年齡提醒不改寫 DDInter 風險，不移除未知成分。一般查詢可使用所有年齡，但目前來源規則僅覆蓋此案例的有限品項。
- 未滿 18 歲兒童分流與 Cypromin 的 65 歲高齡分流是專案人工核對門檻；Somin 的 65 歲門檻來自該品項仿單。都不是通用禁用界線。
